# AlphaStar 동작 원리 정리

> 출처: *Grandmaster level in StarCraft II using multi-agent reinforcement learning* (Vinyals et al., Nature, 2019)

## 한 줄 요약

MLP와 같은 원리(`입력 → 신경망 → 행동 확률`)를 아주 크게 키우고,
**정답 라벨 대신 승패 보상으로 학습(강화학습)** 시킨 것이 AlphaStar다.

```
입력(게임 상태) → 신경망 → 출력(어떤 행동을 할지 확률)
```

MLP 분류기(`입력 → 은닉층 → softmax`)와 근본적으로 같고, 달라지는 점은 아래 세 가지다.

## ① 입력: 종류별로 다른 신경망으로 처리

| 입력 종류 | 예시 | 처리 신경망 |
|---|---|---|
| 유닛 목록 (개수가 매번 다름) | 내 질럿 12기, 적 마린 20기 | Transformer |
| 미니맵 (2D 이미지) | 지형, 시야, 유닛 위치 | CNN (ResNet) |
| 숫자 정보 | 미네랄, 가스, 인구수, 시간 | MLP |

- 세 결과를 합쳐 **LSTM**에 넣는다.
- 이유: 전장의 안개 때문에 현재 화면만으로는 판단할 수 없고, "아까 본 것"을 기억해야 한다.

## ② 출력: 여러 단계로 나눠서 결정 (autoregressive)

"다양한 기능"을 하나씩 코딩한 것이 아니라, 출력을 단계적으로 쪼갰다.

```
1단계: 무슨 행동?     → [공격, 이동, 건설, 생산, ...] 중 softmax
2단계: 어떤 유닛이?    → 행동을 수행할 유닛 선택 (pointer network)
3단계: 어디에/누구에게? → 맵 좌표 또는 대상 유닛
```

- 앞 단계의 결과가 다음 단계의 입력이 된다.
- 결국 **분류 문제 여러 개를 연달아 푸는 것**이고, 각각은 MLP의 softmax 출력과 같은 원리다.

## ③ 학습: 두 단계

1. **모방 학습 (지도학습)**
   - 사람 리플레이 수십만 개로 "이 상황에서 사람은 이 행동을 했다"를 따라 하게 학습
   - 지금까지 해본 지도학습과 같은 방식
2. **강화학습 + 셀프플레이 (League Training)**
   - 보상: 이기면 +1, 지면 −1
   - AI끼리 대결시켜 이긴 판의 행동 확률은 올리고, 진 판의 행동 확률은 내린다
   - 리그: 특정 전략만 노리는 "착취자(exploiter)" AI를 일부러 만들어 메인 AI의 약점을 보완

## 지금 아는 것과의 간극

| 이미 아는 것 | 더 배워야 할 것 |
|---|---|
| MLP, 역전파, softmax | CNN, LSTM, Transformer |
| 지도학습 | 강화학습 (정책 경사, PPO) |
| - | 셀프플레이, 멀티에이전트 학습 |

## 현실적인 기대치

- AlphaStar는 TPU 수백~수천 개로 몇 주 학습 (에이전트당 게임 시간 수백 년 분량)
- 개인이 풀게임에서 프로를 이기는 AI를 만드는 것은 사실상 불가능
- 개인이 해볼 수 있는 것
  - python-sc2로 컴퓨터(Hard)를 이기는 규칙 기반 봇
  - PySC2 미니게임을 강화학습으로 정복
  - 리플레이 데이터로 모방학습 모델 (예: 다음 빌드 예측)
